# Criclive scroll story

A lightweight Three.js cricket scene controlled by scroll, followed by match and editorial concept sections.

## Run locally

```sh
npm install
npm run dev
```

The scorecard is sample design data, not a live match feed. The scene uses procedural geometry and renders only while the story is visible or the page is changing.

## Vercel Analytics

Web Analytics is initialized from the client entry point. Enable Web Analytics in the Vercel project settings to collect deployment data.
